# Linux port note

The Linux desktop port is additive-only. Keep changes for it under `Core/`,
`linux/`, and `scripts/linux/`. Do not edit `Chops/`, `project.yml`,
`Chops.xcodeproj/`, `*.plist`, or `site/` when working on the Linux port.

See `docs/linux.md` for build, run, package, and verification commands.
